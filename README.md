A modern, high-performance personal portfolio website built with the latest web technologies. This project showcases my skills, experience, and projects in a sleek, interactive interface featuring smooth animations and a responsive design.

## 🚀 Key Features

*   **Immersive Hero Section**: Captivating introduction with modern typography and layout.
*   **About Me**: A section dedicated to my background and personal journey.
*   **Experience Timeline**: A vertical timeline visualizing my professional career path.
*   **Achievements**: Highlighted accomplishments and certifications.
*   **Projects Gallery**: Showcase of my best work with details and links.
*   **Contact Form**: Easy-to-use contact section for inquiries.
*   **Custom Cursor & Animations**: Enhanced user experience with `framer-motion` for smooth transitions and a custom cursor.
*   **Responsive Design**: Fully optimized for all device sizes, from mobile to desktop.
*   **Modern Styling**: Utilizes `Tailwind CSS v4` for a clean and maintainable design system.

## 🛠️ Tech Stack

-   **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
-   **Library**: [React 19](https://react.dev/)
-   **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
-   **Animations**: [Framer Motion](https://www.framer.com/motion/)
-   **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
-   **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🏁 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

Make sure you have the following installed:

-   [Node.js](https://nodejs.org/) (Latest LTS version recommended)
-   [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/) or [pnpm](https://pnpm.io/)

### Installation

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/AvadhutK01/my-portfolio.git
    cd my-portfolio
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    # or
    yarn install
    # or
    pnpm install
    ```

3.  **Run the development server**:
    ```bash
    npm run dev
    # or
    yarn dev
    # or
    pnpm dev
    ```

4.  **Open the application**:
    Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
